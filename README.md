# Glowstone

**A different space for your thoughts.**

Glowstone is a 3D note-taking application developed by **Avolor**.

Our goal is to make organizing and exploring your ideas a more visual and engaging experience.

## Download

Glowstone is free.

To download the Windows version, visit the [Releases](https://github.com/sandrodanelia2-wq/AvolorGlowstone/releases) page and download the latest installer.
